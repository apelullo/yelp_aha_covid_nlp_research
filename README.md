# Yelp-AHA COVID-19 NLP Research
* **Description**: A foundational research initiative conducting an in-depth analysis of Yelp health-related facilities, American Hospital Association (AHA) members matched to Yelp facility data, Yelp facility categories, and Yelp facility review content "before" and "after" onset of COVID-19.
  * The analysis is split into three distinct projects using data from **(1)** all Yelp health-related facilities, **(2)** Yelp hospitals, and **(3)** Yelp-AHA-matched hospitals, respectively.
  * For each project, review data is filtered for **(a)** all reviews, **(b)** reviews with one or more COVID-19 keywords, and **(c)** reviews with one or more telemedicine keywords.
  * The outputs of this research inspired further investigation into Yelp review content and other online text sources referencing the COVID-19 pandemic and resulted in a number of publications in top medical journals. 
* **Role**: *Lead Data Scientist* allocated to the Yelp-AHA COVID-19 NLP research initiative
